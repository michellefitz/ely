Adding a bottle today

  1. Find or take a photo. Crop it by hand.
  2. Type title, price, description.
  3. Add tags for type, country, grape, style, vintage.
  4. Hope the photo and the vintage match.

Adding a bottle with the tool

  1. Take one photo.
  2. Confirm the amber fields. Type the price.
  3. Check the studio shot. Approve.
  4. Filters, tags and wine facts fill from the same data.
