Adding a bottle today

  1. Find a photo. Crop it by hand.
  2. Type title, price and description.
  3. Add the product to each filter collection by hand: type, country, region, grape, vintage, style.
  4. Hope the photo and the vintage match.

Adding a bottle with the tool

  1. Take one photo.
  2. Confirm the amber fields. Type the price.
  3. Check the studio shot. Approve.
  4. Filters fill from the wine data. Nothing to add by hand.
